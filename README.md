🌙 Mooncycle Ritual Garden Co.
A multi-page, lunar-inspired website blending botanical aesthetics with modern web standards.

🌿 Overview
Mooncycle Ritual Garden Co. is a responsive e-commerce concept focused on ritual tools and spiritual gardening. It features a cohesive brand design, semantic structure, interactive product displays and games, and a magical checkout experience.

🔧 Tech Stack
Structure: HTML5
Styling: CSS3, Bootstrap 5
Icons: Bootstrap Icons
Scripts: Vanilla JavaScript (cart, modals, checkout)

✨ Features
Responsive Design: Mobile‑first layout using Bootstrap.
Product Catalog: Custom cards with CSS‑only Quick View modals.
Cart System: Add/remove items, quantity updates, and persistent cart badge.
Garden Gate Exit: Full‑page ritual checkout with order number, discount BloomCode, and approval sequence.
Garden Library: Interactive game hub featuring the Chakra Soundboard, Catch the Light, and Paired & Revealed.
Accessible: Semantic headings and descriptive alt‑text.
Animations: Smooth UI with botanical‑spiritual styling.

📁 Pages
Home: Brand introduction and featured collections.
About: Mission and lunar philosophy.
Catalog: Product list with interactive modals.
Cart: Dynamic cart + Garden Gate Exit ritual.
Garden Library: Interactive soundboard and two mini‑games.
Blog: Articles on cycles and gardening.
Contact: Inquiry form and community links.
Legal & Policies: Standard data protection.
